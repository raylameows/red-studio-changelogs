# Red Studio Changelogs

This repository contains changelogs for Red Studio games. The purpose of this is for easier sharing via links and for some games to be able to fetch their changelogs directly from this repository for convenient in-game display.

## Contributions

If you notice missing or incomplete changelogs, feel free to open a pull request to improve them. Contributions may include, but are not limited to:

- Improving changelog readability
- Adding additional information
- Fixing typos or grammar
- Updating outdated or incorrect information

> [!WARNING]
> `GAMES.json` is restricted and may only be modified by Rayla. Pull requests that include changes to this file will most likely be rejected, unless the modification was discussed with Rayla prior.

## Commit Guidelines

Please follow the existing commit naming conventions used in the repository. You are welcome to include detailed descriptions to clearly explain your changes.
